# Codex instructions — peetkaa63 portfolio

## Project
This is a static personal portfolio hosted on GitHub Pages.
GitHub Pages publishes the `docs/` folder from the `main` branch.
The page is `docs/index.html`, styles and scripts are in `docs/assets/`.

## Before making changes
- Read the existing HTML, CSS, JS and project links. Do not replace the site with a generic template.
- Respect the existing Russian language, layout, responsiveness and accessibility.
- Keep all assets local under `docs/` where possible, using relative URLs compatible with the GitHub Pages project path.
- Do not claim that a prototype is deployed or that all features work without evidence.
- Credit collaborative work accurately, and do not invent employers, clients, revenue, testimonials or skills.
- Never add API secrets, login data, tracking scripts or third-party embeds without approval.

## Working safely
- Work on a feature branch and open a Pull Request. Do not push directly to `main` or publish without the owner's review.
- Check modified local paths, internal anchors, page semantics, image alt text, keyboard behavior and mobile layout.
- Run `python3 scripts/check_portfolio.py` and `node --check docs/assets/main.js` when those files are available.
- Describe checks actually run, and list any checks you could not run.
- Remember that merging to `main` can trigger automatic website publication.

## Completion report
In Russian, summarize changes, files touched, test results, expected visual changes, any remaining risks and the Pull Request URL.
