# Аудит портфолио — 30 октября 2026

Проверена версия `main` на коммите `1ab2677`: главная, Commit to Learn, TestOps Copilot, общие HTML/CSS/JS, локальные ресурсы, метаданные и CI. Опубликованная главная отвечает HTTP 200 и совпадает с исходным HTML этой версии.

## Найденные ошибки и исправления

| Проблема | Как воспроизвести / влияние | Исправление |
| --- | --- | --- |
| Фокус брифа оказывался за экраном | При 390 × 320 поле задачи получало фокус, но находилось ниже видимой области: верх 434 px, низ 537 px. | Поле прокручивается в видимую область с учётом закреплённой шапки. |
| Меню не помещалось в коротком окне | При высоте 240 px последняя ссылка выходила за нижнюю границу. Номера также примыкали к тексту ссылок. | Ограничена высота меню, добавлена внутренняя прокрутка, текст и номера разнесены. Без JS меню остаётся полностью раскрытым. |
| Сохранённое отключение анимации применялось поздно | При заблокированном `main.js` заголовок продолжал анимироваться, хотя настройка уже сохранена. | Настройка читается в head-скрипте до CSS и первого кадра. |
| Настройка анимации расходилась между вкладками | Переключение в другом окне не обновляло текущую страницу. | Добавлены обработчики `storage` и `pageshow`; локальный выбор сохраняется в текущей странице и при ошибке записи. |
| Черновик мог расходиться с восстановленными полями | Браузер восстанавливал значения после инициализации JS, а сообщение оставалось прежним. | Сообщение пересобирается на `pageshow`; данные по-прежнему не сохраняются приложением. |
| Старый ответ копирования перезаписывал новый | Два запроса Clipboard API завершались в обратном порядке; устаревший ответ мог заменить успешное уведомление. | Уведомление и ручной fallback обновляет только последняя попытка. |
| Подсветка меню кейса исчезала | При переходе в раздел результатов TestOps Copilot активная ссылка сбрасывалась: раздел отсутствует в верхнем меню. | Подсветка отслеживает только разделы, представленные в навигации. |
| Ctrl/Cmd-клик скрывал мобильное меню | Открытие ссылки в другой вкладке закрывало навигацию текущей страницы. | Меню закрывается только при обычном переходе. |
| Замечание axe к структуре ориентиров | `landmark-complementary-is-top-level`: пример кода был размечен вложенным `aside` внутри `main`. Это замечание best-practice, не отдельный провал WCAG. | Использован именованный `section` с существующим заголовком. |
| Пробелы в статической проверке | Query-only ссылки ошибочно считались отсутствующими файлами; якоря ссылок на папку не проверялись. | URL без пути относится к текущей странице, ссылки на папки разрешаются через `index.html`. Добавлены проверки H1, текста title, label/ARIA-ссылок и sitemap. |

Семь регрессий отдельно воспроизведены новыми тестами на исходной версии: видимость поля, раннее отключение анимации, синхронизация настройки, восстановление черновика, порядок ответов Clipboard API, подсветка меню и высота мобильной навигации. Все семь тестов падали до исправлений и проходят после них.

## Добавленные улучшения

- Sitemap для трёх страниц и проверка его соответствия canonical URL.
- Закреплённая версия axe-core для тестов доступности. В код опубликованного сайта библиотека не добавляется.
- Проверка одного набора сценариев в Chromium, Firefox и WebKit через CI. Существующее имя проверки `browser-checks` сохранено.
- Скриншоты при падении браузерных сценариев, чтобы упростить диагностику в CI.
- Проверка приватности брифа: введённый HTML остаётся текстом, данные не попадают в localStorage/sessionStorage, запросы и ссылку Telegram.

## Проверки

- `python3 scripts/check_portfolio.py`: все три HTML-страницы, якоря, ресурсы, структура, ARIA/label-ссылки и sitemap.
- `python3 -B -m unittest discover -s scripts -p 'test_*.py'`: 14 тестов.
- `node --check docs/assets/main.js` и `node --check docs/assets/theme.js`.
- Браузерный набор: 26 сценариев. Локально прошёл в Chromium и Firefox. Включает 320 / 390 / 760 / 1440 px, обе темы, клавиатуру, no-JS, бриф, галерею, хранилище, анимации и дополнительные короткие окна 390 × 320 и 390 × 240.
- axe-core: все страницы в обеих темах при 390 и 1440 px, включая раскрытый бриф и галерею. После исправления вложенного ориентира автоматических нарушений выбранных правил в Chromium и Firefox не обнаружено.
- WebKit локально не запустился из-за отсутствующих системных библиотек. Для него добавлен отдельный CI-job с установкой зависимостей; его результат нужно смотреть в PR.
- Скриншоты до/после: `.github/previews/audit-brief-*.jpg` и `audit-menu-*.jpg`.

## Границы аудита

Проверен статический сайт портфолио. Исходные приложения TestOps Copilot / Commit to Learn / Smart Warehouse, их API, базы и развёрнутые сервисы не запускались и не изменялись. Качество AI-генерации и авторство отдельных модулей не оценивались.

Автоматический axe не доказывает полное соответствие WCAG. Отдельная ручная проверка VoiceOver/NVDA, физических устройств и Safari на iOS не выполнялась; WebKit в CI проверяет браузерный движок. Перед публикацией остаётся визуальный просмотр владельцем. GitHub Pages по-прежнему использует `main` → `/docs`; объединение PR может автоматически опубликовать изменения.
