01 / Контекст

Один продукт.
Две роли.

Преподаватель создаёт курс и задания. Студент записывается на курс и отправляет работу. Сервер связывает эти действия с пользователем и проверяет доступ.

Моя роль Backend Developer указана в README команды «Сваровски». Ниже — технический разбор проверенной версии командного репозитория.

02 / Путь запроса

От HTTP-запроса
до записи в базе.

На примере создания курса: маршрут, проверки, контроллер и доступ к данным. Схема следует вызовам в исходниках.

  1. 01 / Вход

    Маршрут Express

    POST /api/courses подключает аутентификацию, проверку роли преподавателя и валидаторы полей.

  2. 02 / Обработка

    Контроллер

    createCourse проверяет результат валидации, берёт данные из запроса и связывает курс с текущим преподавателем.

  3. 03 / Доступ к данным

    Репозиторий

    Вызов courseRepository.create использует общий BaseRepository для создания записи через Prisma.

  4. 04 / Хранение

    Prisma + PostgreSQL

    Модель Course задаёт поля и связи курса. После успешного создания контроллер возвращает ответ 201.

{ }

Роль пользователя — часть сценария

В маршрутах курса создание доступно роли TEACHER, а самостоятельная запись — STUDENT. При чтении курса контроллер проверяет запись студента или принадлежность курса преподавателю.

03 / Модель данных

Учебный процесс
в связях данных.

Основные сущности из Prisma-схемы. Описания помогают прочитать структуру проекта без запуска серверной части.

UserПользователь
Студент или преподаватель. Роль определяет доступные действия; пользователь связан с курсами и отправленными работами.
CourseКурс
Принадлежит преподавателю и объединяет материалы, задания и записи студентов на обучение.
CourseEnrollmentЗапись на курс
Связывает студента с курсом. Для пары «студент — курс» в схеме задано ограничение уникальности.
AssignmentЗадание
Связано с курсом, содержит описание, срок сдачи и максимальный балл. Объединяет отправленные работы.
SubmissionРабота студента
Связана со студентом и заданием. Хранит ссылку на файл и статус; может иметь оценку, комментарии и версии.
Связи в кодеИсточник модели

Полная схема содержит и другие сущности: материалы, оценки, тесты и группы.
