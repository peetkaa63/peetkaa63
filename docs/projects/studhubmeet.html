Особое внимание — согласованности поиска, реакций и диалогов между интерфейсами. Исправление одного сценария требует проверки связанных действий пользователя.

03 / Технологии

Из чего
собран сервис.

Исходники закрыты. В разборе представлены назначение продукта, мой вклад и основные сценарии без публикации кода.

Пользовательские интерфейсы
Telegram-бот на Python / aiogram и Mini App на Flutter / Dart. Два способа взаимодействовать с одним сервисом.
Сервер и данные
Node.js / Express и PostgreSQL. Общая серверная часть связывает анкеты, реакции и сценарии общения.
Администрирование
Интерфейс на React и сценарии модерации. Пользовательская и административная части рассматриваются вместе.
